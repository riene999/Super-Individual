## 适用场景
新增一个页面或在已有页面下加一个子标签页（Tab），通常需要后端提供数据接口 + 前端新建组件 + 注册路由 + 在导航处加入口。

## 实现指引
端到端通常涉及（按需取舍，但"建了页面却没入口/没路由/没接口"是常见漏项，务必自查）：
- 后端数据接口：在 `backend/controllers/` 加处理函数，并在 `backend/routes/` 对应路由文件里**注册路由**把它挂上（只写 controller 不挂路由 = 接口 404）。注意路由顺序：带具体路径的（如 `/drafts`）要放在 `/:slug` 这类参数路由之前，否则会被参数路由吞掉。
- 前端组件：在 `frontend/src/routes/` 下新建页面组件；可参考同目录已有的同类组件（如 `HomeArticles.jsx`、`Profile/ProfileArticles.jsx`）保持风格、数据拉取方式一致。
- 路由注册：在 `frontend/src/main.jsx` 导入新组件并加 `<Route>`；子标签页要挂在对应父路由下。
- 导航入口：在导航/标签容器（如 `Profile/Profile.jsx` 的 NavItem 列表、Navbar）里加入口链接，否则用户没有可点的入口。

## 命名一致性（重要）
新建组件的文件名、默认导出名、main.jsx 里的 import 名、路由 path、后端接口路径必须在 contract 里钉死并全程一致，不要在不同文件里各起一个名字。

## 需要澄清的点
- 路由路径与页面/Tab 名称。
- 数据从哪些表/字段聚合、排序规则。
- 入口放在哪里；该页面/Tab 的可见性（如个人主页 Drafts 是否仅本人可见）。
